# Setup

## 1. Remove cards by player count

Set the number of **employee cards used** of each type and remove some billboards
depending on player count:

| Players | Employee copies used | Billboards removed | Map size |
|---------|----------------------|--------------------|----------|
| 2 | 1 | #12, #15, #16 | 3×3 |
| 3 | 1 | #15, #16 | 3×4 |
| 4 | 2 | #16 | 4×4 |
| 5 | 3 | none | 5×4 |

Put the removed billboards back in the box.

## 2. Map setup

Create the map by randomly selecting the required number of map tiles, **rotating
each tile randomly**, and placing them in a grid of the size above.

## 3. Filling the bank

Place **$50 × number of players** into the bank pool (use small bills). The rest
of the money stays in the box for now. Players start with **no money**.

## 4. Player markers

Each player chooses a restaurant chain and receives:

- 1 **CEO** card,
- 3 **restaurants**,
- a set of 3 **bank reserve** cards.

## 5. Initial order of play

Collect the turn-order markers of the chosen chains, shuffle them, and draw them
randomly onto the turn-order track in draw order.

## 6. Placing the first restaurants

Each player places **one** starting restaurant. Go from **last** in turn order to
**first**. Each player may place a restaurant **or pass**. If anyone passed, a
second round is played in turn order; each player who has not yet placed must now
place. Players who already placed do not participate in the second round.

Initial placement limitations:

- Restaurants must be placed **fully on empty squares** (no other restaurants,
  roads, drinks, or houses).
- The restaurant's **entrance must border a road square**.
- A restaurant may **not** be placed so its entrance is on the **same tile** as the
  entrance of an existing restaurant.

## 7. Setting goals (bank reserve)

Each player secretly chooses **one** of their 3 bank reserve cards and places it
face down next to the bank. The other two reserve cards are discarded unseen.

The chosen reserve cards **collectively** determine how much money is added when
the bank first runs out (higher total = longer game). Players won't know the exact
game length, which is deliberate. Each reserve card also shows **2, 3, or 4 open
slots** — used later to reset the number of CEO slots (see
[08-bank-and-endgame.md](08-bank-and-endgame.md)).

---

## Introductory-game changes

For a first game, apply the beginner variant (see
[09-introductory-and-strategy.md](09-introductory-and-strategy.md)): no reserve
cards, $75 × players in the bank, no milestones, skip Payday, and the game ends
when the bank breaks **once**.
